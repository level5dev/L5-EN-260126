CHOOSING YOUR HANDLES

All LEVEL5 handles feature a robust, yet lighweight aluminium construction.

Fixed Length Handles: Ideal for everyday job site conditions when standard walls, ceilings etc. If selected, your set will include:

  • 4-712 - 42” Fixed Flat Box Handle
  • 4-779 - 54” Corner Finisher Handle
  • 4-778 - 50” Corner Applicator Handle
  • 4-777 - 54” Corner Roller Handle

Extendable Handles: If your job site conditions will vary dramatically, and you need added flexibility for reaching high walls & ceilings, or shrinking down to finish closets and tight spaces, consider selecting extension handles. If selected, your set will include:

  • 4-780 - 40” - 62” Extendable Flat Box Handle
  • 4-795 - 31” - 50” Extendable Corner Finisher Handle
  • 4-794 - 31” - 50” Extendable Corner Applicator Handle
  • 4-792 - 31” - 50” Extendable Corner Roller Handle
